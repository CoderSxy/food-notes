# Leaflet 地图足迹设计

**日期：** 2026-10-31  
**状态：** 已确认  
**仓库：** CoderSxy/food-notes  
**前置：** `docs/superpowers/specs/2026-10-28-entries-items-design.md`（entries 已有可选/必填 `lat`/`lng`）

## 1. 目标

为 food-notes 接入**免费**地图：在首页与详情展示有坐标登记的足迹标记；在登记页支持地图点选/拖钉确认位置。本轮不做路线、热力、离线包或独立 `/map` 页。

### 已确认决策

| 项 | 选择 |
|----|------|
| 技术栈 | `leaflet` + `react-leaflet`；`next/dynamic` 且 `ssr: false` |
| 底图瓦片 | OpenStreetMap 标准瓦片 |
| 表面 | ① 首页列表上方大地图总览 ② 详情有坐标时小地图 ③ `LocationField` 旁可交互选点（点选或拖钉），保留定位按钮与手填经纬度 |
| 标记范围 | 所有有 `lat`/`lng` 的登记（`place` + 有坐标的 `item`） |
| 范围筛选 | 默认「我的」，可切换「全部」 |
| 数据 | **不新建表**；复用现有 entries 查询 |
| 明确不做 | MapLibre、iframe 嵌图、国内专用瓦片商、本轮独立 `/map`、路线/热力/离线 |

## 2. 架构

### 2.1 组件

| 组件 | 职责 |
|------|------|
| `EntriesMap` | 首页总览多点；「我的 / 全部」过滤；`fitBounds`；marker 气泡 |
| `EntryMiniMap` | 详情只读单点小地图（无坐标则不渲染） |
| `LocationPickerMap` | 登记页可点选/拖钉，写回 `lat`/`lng`，与 `LocationField` 双向同步 |
| 共用 helpers | 瓦片 URL、默认中心、marker 图标/样式（避免三处复制） |

地图相关 UI 一律走客户端组件，通过 `next/dynamic(..., { ssr: false })` 挂载，避免 Leaflet 触碰 SSR / hydration。

### 2.2 数据

- 来源：现有 entries 列表/详情查询（过滤 `lat`/`lng` 非空）。
- 「我的」：按当前登录用户 `user_id` 过滤；「全部」：不过滤用户。
- 登记写回：仍走现有创建/更新 API 的 `lat`/`lng` 字段，无新 endpoint。

### 2.3 与现有字段的关系

- `place`：坐标仍必填；可用地图点选补齐，也可用定位/手填。
- `item`：地点可选；无坐标则不进地图、详情不显示小地图。

## 3. 交互（UX）

### 3.1 首页总览

- 大地图嵌在列表**上方**。
- 「我的 / 全部」切换；切换后重算标记与 `fitBounds`。
- 点击 marker：气泡展示名称、评分、链到详情。
- 无任何有坐标点时：显示友好空态（提示去登记或切「全部」），不报错。

### 3.2 详情小地图

- 仅当该 entry 有坐标时渲染只读小地图。
- 可选：点击外开 OSM（非必须，实现时可加）。

### 3.3 登记选点

- `LocationField` 旁挂 `LocationPickerMap`。
- 支持：点地图设钉、拖钉改坐标；定位按钮与手填经纬度仍保留。
- 任一路写入的 `lat`/`lng` 与钉位置同步。
- 尚无坐标时：默认中心可用「用户最近一次定位」或中国大致中心，并提示点选/拖钉。
- `place` 提交前仍须有坐标；`item` 可不选点。

### 3.4 视觉与端

- 样式贴合「温暖食记」卡片气质（圆角、暖色点缀即可，不强行换主题）。
- PC 与移动都可用（触摸拖钉需可用）。

## 4. 错误与 SSR

- 地图**仅客户端**挂载；不在服务端渲染 Leaflet DOM，避免 hydration 属性不匹配。
- 瓦片或脚本加载失败：显示「地图加载失败」占位；列表、表单、手填经纬度、定位按钮仍可用。
- OSM 在部分网络偏慢：可接受；本轮不切国内瓦片商（已在决策中排除）。

## 5. 测试

| 类型 | 覆盖 |
|------|------|
| 单元 | 有坐标过滤；「我的 / 全部」；picker 写回 `lat`/`lng`；详情有/无坐标分支 |
| 烟雾 | 地图容器在首页/详情/登记相关页面存在（客户端挂载后） |

不强制对真实 OSM 瓦片做 E2E 网络依赖测试。

## 6. 本轮范围外

- MapLibre GL / 矢量底图
- iframe 第三方小地图
- 中国大陆专用瓦片供应商
- 仅登记选点、不做首页总览
- 独立 `/map` 路由页
- 路线、热力图、离线包、聚类（点很多时的高级聚合可后续再议）

- [ ] 首页有总览图，默认「我的」，可切「全部」，有坐标点均可见
- [ ] marker 气泡含名称/评分/详情链接，且 `fitBounds` 合理
- [ ] 详情有坐标显示只读小地图，无坐标不渲染
- [ ] 登记可点选与拖钉，与定位/手填同步
- [ ] 无新表；列表与表单在地图失败时仍可用
- [ ] 无 Leaflet 相关 hydration 警告
